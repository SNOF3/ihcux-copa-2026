# ihcux-copa-2026
aula interação e UX 
Problema
Dificuldade do torcedor em:
- enfrentar filas,
- se localizar no estádio,
- acompanhar lances importantes.

 Justificativa de Design
Interface simples e rápida:
- Home com placar e atalhos;
- Mapa para localização;
- Cardápio organizado por categorias;
- Carrinho com resumo claro;
- Replays fáceis de acessar;
- Ingresso com QR Code direto.

Fluxo do Usuário
Pedir lanche:
Home → Cardápio → Adicionar itens → Carrinho → Pagamento.
Ver replay:
Home → Replays → Escolher vídeo.
